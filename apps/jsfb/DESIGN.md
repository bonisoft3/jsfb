# The benchmark's own look

This app does not have a design; it has a **reference**. The page is
js-framework-benchmark's, and its element ids, class names, table structure and
button captions are the published implementation's. Changing them would make
the app useless for the one thing it is for.

What is ours is the palette. The Bootstrap classes are reproduced from the
`press` preset's tokens — `--accent` for the primary button, `--surface-muted`
for the jumbotron, `--danger` for the selected row's `.danger` class, `--border`
for the table rules — so the app is legible in both themes without naming a
single hex.
